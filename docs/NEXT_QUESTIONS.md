# 次に利用者へ確認すると効くこと

今すぐ全部聞く必要はありません。MVPを触ってもらい、違和感が出た箇所から確認する想定です。

1. **主に左手用ですか、両手用ですか？**
   - 左手でコンピングしながら右手でソロする用途なのか
   - 両手で厚いボイシングを作りたいのか

2. **ベーシストがいる前提が多いですか？**
   - いるならrootless中心
   - ソロピアノならrootを含む候補が重要

3. **1コード何音くらい欲しいですか？**
   - 3音 / 4音 / 5音 / 6音

4. **メロディの音を一番上に固定したいですか？**
   - これがYESなら、ボイシング生成器としてかなり重要な制約になります

5. **欲しいボイシング語彙はどれですか？**
   - Rootless A/B
   - Spread
   - Quartal
   - So What
   - Upper Structure Triad
   - Cluster
   - Drop 2
   - その他、普段使っている名称

6. **コード記号はどこから持ってきますか？**
   - 手入力
   - iReal Pro等からコピー
   - MusicXML
   - テキストファイル

7. **ランダム性はどの単位ですか？**
   - 各コードごとに自由に抽選
   - 進行全体としてvoice leadingが自然なテイクを抽選
   - 今のMVPは後者寄りです

8. **MIDIには何を入れたいですか？**
   - ブロックコードだけ
   - コンピングのリズム
   - ベースも別トラック
   - ベロシティの揺れ
   - スウィング

9. **同じコード進行から何案ほしいですか？**
   - 1案を再抽選
   - 4案を並べて比較
   - 10案生成して気に入ったものを保存

10. **『これは絶対に避けたい』ボイシングはありますか？**
    - 音域
    - 半音クラスター
    - ルート重複
    - 特定テンション
    - 手が届きにくい幅
